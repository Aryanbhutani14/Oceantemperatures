# Decision log

Every methodological decision is recorded here with its date, rationale and
status.

| ID | Date | Decision | Status | Rationale |
|---|---|---|---|---|
| D-001 | 2026-11-17 | Models are restricted to the CSE2032 syllabus (regression, regularization, classification, ensembles, PCA). | Accepted | Course project for CSE2032 |
| D-002 | 2026-11-17 | Canonical grid = problem-statement grid: cell centres 5–30°N × 45–105°E at 0.25° (101 × 241), daily UTC, 15 standard depths. | Accepted | Fixed by the problem statement |
| D-003 | 2026-11-17 | **Study period = one year, 2021-01-01 → 2021-12-31.** | Accepted | Submission deadline. 2021 includes cyclones Tauktae, Yaas, Gulab, Shaheen and Jawad, plus 4,071 ARGO profiles. |
| D-004 | 2026-11-17 | Target: GLORYS member of the CMEMS ensemble reanalysis (`thetao_glor`, 0.25°). Its grid centres coincide exactly with ours, so no horizontal regridding is needed. | Accepted | Audit: centre offset (0, 0) |
| D-005 | 2026-11-17 | Winds: CMEMS L4 scatterometer winds (ASCAT-based, `WIND_GLO_PHY_L4_MY_012_006`, hourly 0.125°) averaged to daily. CCMP v3.1 is optional. | Accepted | The problem statement names ASCAT; same login and server-side subsetting as the other CMEMS products |
| D-006 | 2026-11-17 | ARGO is used for validation only and never for training or tuning. | Accepted | Independence |
| D-007 | 2026-11-17 | Satellite gaps are never filled in the data cube; NaN is preserved. | Accepted | No fabricated observations |
| D-008 | 2026-11-17 | **Split by whole months:** test months = Feb, May, Aug, Nov (one per season); train months = the other 8. A 7-day buffer next to each test month is dropped from training. Cross-validation is GroupKFold with groups = month. | Accepted | With only one year, a chronological split would leave whole seasons unseen. Month blocks plus buffers limit autocorrelation leakage. **Never a random row split.** |
| D-009 | 2026-11-17 | Surface currents: DUACS geostrophic currents (`ugos`, `vgos`). OSCAR v2 is optional (needs a NASA Earthdata login). | Accepted | Same download as SLA; documented deviation from the problem statement (OSCAR = geostrophic + Ekman) |
| D-010 | 2026-11-17 | Climatology for the baseline and anomaly target = **external** GLORYS12 multi-decade monthly climatology, not computed from 2021. | Accepted | One year can't produce a climatology without leaking test months. An external climatology is leakage-free. |
| D-011 | 2026-11-17 | Model shortlist follows the CSE2032 syllabus: Linear Regression (incl. gradient descent from scratch), Ridge, Lasso, KNN, Decision Tree, Random Forest, Bagging, Gradient Boosting / AdaBoost, SVR (subsample), PCA. Optional extras: ElasticNet, XGBoost. | Accepted | Course scope, plus a little extra |
| D-012 | 2026-11-17 | Corrected product IDs: SSS = `MULTIOBS_GLO_PHY_S_SURFACE_MYNRT_015_013` (the planned `..._014_001` does not exist); CCMP = `CCMP_WINDS_10M6HR_L4_V3.1`. | Accepted | Phase 0 audit |
| D-013 | 2026-11-17 | Downloads are subset on the server (padded bbox 44.5–105.5°E, 4.5–30.5°N; depth 0–1046 m), month by month, written atomically (`.part` → `.nc`) and never modified afterwards. A SHA-256 manifest is kept. | Accepted | Reproducibility; restarting a run is safe |
| D-014 | 2026-11-17 | SSS dataset version `202311` is flagged for retirement on 2026-11-24. The exact version used is recorded in the download log, and the raw files are kept. | Noted | Provenance |
| D-015 | 2026-11-17 | Harmonised data are stored as compressed NetCDF (`data/interim/*.nc`), not Zarr. | Accepted | At 0.25° for one year the files are small (~260 MB in total), so Zarr's chunking adds nothing and would be an extra dependency |
| D-016 | 2026-11-17 | Temperature plausibility upper limit raised from 35 to **38 °C**. | Accepted | Persian Gulf summer SST is genuinely 35–36.7 °C. A 35 °C limit deleted real extremes (863 target and ~119k OSTIA values). |
| D-017 | 2026-11-17 | One conservative (area-weighted) regridding operator is used for all sources. It reduces to identity or an exact block mean where grids nest. Coastal cells with no satellite data stay NaN. | Accepted | Consistent, tested (`tests/test_regrid.py`), no fabricated values |
| D-018 | 2026-11-17 | Primary target = **anomaly** `a = T − external climatology`; prediction = climatology + predicted anomaly. Absolute temperature is kept for ablation. | Accepted | Phase 3 EDA: the climatology removes most of the variance (surface std 1.73 → 0.67 °C) |
| D-019 | 2026-11-17 | Features are engineered on the grid, then flattened (40 features, `configs/features.yaml`). Temporal windows are trailing only, 7 days (= buffer). | Accepted | Spatial features need neighbours; past-only windows avoid temporal leakage |
| D-020 | 2026-11-17 | Surface-pattern summary = PCA of standardised 3×3×7 surface patches → 8 components, fitted on train days only. | Accepted | Compact summary of the local surface pattern using a syllabus method (PCA) |
| D-021 | 2026-11-17 | Project structure: installable package `src/oceanembed_ml` (`pip install -e .`), thin CLIs `scripts/NN_*.py`, executed notebooks in `notebooks/` for exploration/EDA only, raw/processed data git-ignored. | Accepted | Course requirement: a proper GitHub Python project with reproducible phase outputs |
| D-022 | 2026-11-17 | Model selection = lowest **GroupKFold-by-month CV** RMSE on train months, never test scores. An averaging ensemble is adopted only if it improves CV RMSE by ≥ 1%. The GB+RF ensemble gained 0.004%, so it was **not adopted**; **Gradient Boosting is selected**. | Accepted | Avoids adding complexity for presentation; the choice is fixed before test results are seen |
| D-023 | 2026-11-17 | Training-sample sizes: 400k rows (KNN 150k, SVR 10k), tuning set 120k, a fixed 200k-row test subset for all models (fingerprinted). | Accepted | Compute: SVR prediction is O(n_SV) per row (45 min for 200k rows); the Phase 5 ablation learning curve checks that 400k rows is enough |
| D-024 | 2026-11-17 | **Revises D-018.** Final target = anomaly **with the climatology at that depth as an extra input feature**, chosen by GroupKFold-by-month CV (0.5385 vs 0.5772 anomaly-only vs 0.5562 absolute). It was triggered by a test-set ablation, but the decision was made only on CV. | Accepted | The external climatology has its own 2021 errors; as a feature the model can correct them. Final test RMSE 0.579 °C, skill 0.636 |
